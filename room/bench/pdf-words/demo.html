What does a PDF say underneath?

A scanned PDF is often a picture of each page with the scanner's own reading of it hidden behind, as invisible text. This page reads that text out, page by page. It is under 500 lines of plain code with no PDF library, and your file never leaves this browser.

Drop a PDF here, or or

The sample is a two-page PDF made by this build's own fixture code, built into the page.

Reads: compressed and uncompressed pages, object streams, ToUnicode maps, WinAnsi and /Differences, form XObjects. Refuses: locked (encrypted) PDFs. Stops any one stream at 32 MB. A page with no text layer comes out empty: that's a scan nobody read.
